What is LotCAD?

LotCAD combines 2D drafting, 3D modeling and Vulkan visualization in a cross-platform CAD application. Its C API also lets developers bring the engine into their own desktop and mobile apps.

Model and edit

Create sketches, boxes, cylinders and extruded profiles. Edit supported feature dimensions, add pockets and through-cuts, and keep changes in a native LotCAD project.

Draw and document

Work with lines, arcs, text, dimensions and hatches. Create projected drawing views and sections, then export supported drawing linework to PDF or PNG.

Visualize and integrate

Explore assemblies, imported models and robot motion. Use the SDK examples to connect rendering and CAD commands to your own application.

Choose a native project for editing, a mesh format for exchange, or a drawing format for documentation. Linked examples are available to open or download; other filenames illustrate each format's use.
